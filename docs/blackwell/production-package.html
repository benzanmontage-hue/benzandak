10. PRE-PRODUCTION CHECKLIST

  • Confirm fabric: request 220GSM organic cotton swatch in charcoal
  • Confirm print: send vector file (AI/EPS) with Pantone references
  • Confirm label: send woven label artwork to trim supplier
  • Confirm size set: order 1 sample per size (S-XXL) for fit approval
  • Confirm wash: request 47-min enzyme wash sample vs non-washed
  • Approve strike-off: screen print test on actual fabric before production
  • Approve packaging: order 1 sample of each packaging item
  • Photography: book photographer for lookbook + e-commerce flats
  • Webshop: prepare product page, size guide, shipping zones
  • Launch plan: date, inventory, email list, social campaign
