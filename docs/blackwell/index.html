His Inventions

THEOREM 01
Rao-Blackwell
E[δ(X) | T] ≥ δ(X)
Every estimator can be improved by conditioning on a sufficient statistic. You start raw and refine until pure signal remains — the same process as designing a garment.
THEOREM 02
Renewal
limt→∞ P(N(t) > 0) = 1
Systems that reset stochastically always converge. Every collection is a renewal — each drop restarts the clock with better information.
THEOREM 03
Channel Coding
C = max I(X; Y)
The Blackwell channel measures information flow through noisy systems. Signal through noise. Meaning through static. Luxury is clarity.
THEOREM 04
Approachability
dist(Sn, A) → 0
In repeated games, a player can force the average payoff arbitrarily close to any target set. Iterate. Improve. Approach the asymptote. Never stop.
THEOREM 05
Dynamic Programming
V(s) = maxa [R(s,a) + γV(s')]
Optimal decisions decompose into recursive subproblems. Build the foundation. Stack the layers. Each choice informs the next.
THEOREM 06
Comparison of Experiments
X ⪰B Y
Blackwell ordering: one experiment dominates another if it contains more information. Better data wins. Better design wins. Precision over excess.
